# CAD 练习作品集

机电一体化专业 · 大一 · 自学 CAD 的练习作品。

按**中国国标（GB）**绘制，投影用**第一角法**，单位 **毫米**。

## 作品清单

| 文件 | 内容 | 练到的技能 |
|---|---|---|
| `任务1 矩形.dxf` | 100×60 矩形 + 正中 φ20 圆孔 + 十字中心线，三个尺寸（100 / 60 / φ20） | 直线、圆、中心线（点划线）、线性标注、直径标注 |

| `任务3.dxf` | 120×40 长条板 + 3×φ10 孔（间距 40）+ 十字中心线 | 复制、链式标注、**引线标注 3×φ10** |

---

## 制图规范

- **投影法**：第一角法（主视图左上、俯视图正下、左视图正右）
- **三等关系**：长对正、高平齐、宽相等
- **线型分工**：
  - 粗实线 —— 可见轮廓
  - 虚线 —— 不可见轮廓
  - 点划线 —— 轴线 / 对称中心线
  - 细实线 —— 尺寸线 / 剖面线
- **中心线**两端各超出轮廓 3～5 mm
- **尺寸线**与轮廓保持 7～10 mm，不与轮廓线重合
